# W.I.T.C.H.🧙‍♀️

Wolverhampton Instrument for Teaching Computing from Harwell

This emulator was inspired by [WITCH-e](https://github.com/technobaboo/witch-e).

I was starting to fork it, but decided on writing my own from scratch to better understand the machine. The examples from WITCH-e are included with the original license in the examples directory.
